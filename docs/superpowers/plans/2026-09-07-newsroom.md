# Newsroom Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A standalone `/newsroom` route that needs no draft in progress: every board player browsable with their card, and a live feed of updates ranked by how much they matter to a drafter (severity × ADP relevance × recency).

**Architecture:** One pure engine module ranks updates (`lib/engine/newsImportance.ts`); the page reuses `useLiveSignals` and `gradeBoard` from Phase 1 unchanged, and `PlayerModal` in its existing `readonly` mode. No new I/O.

**Tech Stack:** Next.js App Router route + client component, existing Tailwind tokens, vitest.

**Spec:** `docs/superpowers/specs/2026-09-07-freshness-and-newsroom-design.md` §Phase 4.

## Global Constraints

- Engine stays pure: `now` is a parameter; no `Date.now()` inside `lib/engine/`.
- Live updates never reorder the feed under the cursor: new items are held behind an "N new" pill while the user is scrolled down.
- Reuse tokens from `app/globals.css` (`bg-panel`, `text-ink-dim`, `text-warn`, `font-display`, position colors via `POS_COLOR`).

### Task 1: Importance model (pure)

**Files:** Create `lib/engine/newsImportance.ts`; Test `tests/newsImportance.test.ts`.

**Interfaces:**
- `type NewsKind = "season-ending" | "suspension" | "out" | "transaction" | "doubtful" | "cleared" | "questionable" | "depth" | "mention"`
- `KIND_SEVERITY: Record<NewsKind, number>` = 1 / .9 / .7 / .6 / .5 / .4 / .35 / .3 / .1; `KIND_LABEL: Record<NewsKind, string>`
- `classifyKind(text: string): NewsKind` — hard signals via `classifyNews`, then cleared / questionable / transaction / depth phrase lists, else mention.
- `relevanceOf(adp: number): number` = `1 − 0.8·min(max(adp,0),300)/300`
- `recencyOf(ageHours: number, halfLifeHours = 12): number` = `0.5^(age/halfLife)`
- `importanceOf(kind, adp, ageHours): number` = `severity × (0.4 + 0.6·relevance) × recency`
- `sourceLabel(href: string | null): string`
- `interface FeedItem { id; playerId; name; pos; team; adp; headline; href; published; source; kind; severity; importance; statusChange?: { from: string | null; to: string | null } }`
- `buildFeed(board: Board, news: ReadonlyMap<string, PlayerNews>, liveStatus: ReadonlyMap<string, { status: FeedStatus; date: string; note: string | null }>, now: number): FeedItem[]` — one item per player headline plus one per status change vs the baked board (via `reconcileStatus`), sorted by importance desc then published desc.

Steps: failing test → implement → pass → commit `Engine: news importance model for the Newsroom (pure)`.

### Task 2: Newsroom page

**Files:** Create `components/Newsroom.tsx`, `app/newsroom/page.tsx`; Modify `components/Setup.tsx` (header link), `components/Cockpit.tsx` (⋯ menu link).

- `app/newsroom/page.tsx` renders `<Newsroom />` with metadata title "Newsroom — Draft Cockpit".
- `Newsroom` loads `/data/board-<scoring>.json` with `cache: "no-cache"` (scoring from `loadConfig()?.scoring ?? "ppr"`), then renders `NewsroomInner` which calls `useLiveSignals(board)`, `gradeBoard`, `buildFeed(board, live.boardNews, live.liveStatus, now)`.
- Layout: header (← Cockpit, title, board age, Refresh button); live strip (Jetstream dot, last refresh, updates in the last hour, status changes, injury counts Q/D/O/IR among ADP ≤ 200, 🔥 trending names); filters (position chips, team select, severity floor chips, search); "What matters" feed with importance bar, kind pill, player, headline, source · age, links; "N new" pill logic; full player table (ADP, player + badges, pos, team, bye, proj, tier, latest note) with show-100/show-all; `PlayerModal` readonly on click.
- Setup header gets a `Newsroom →` link; Cockpit ⋯ menu gets a `Newsroom` entry (opens in a new tab so the draft stays put).

Steps: implement → `pnpm exec tsc --noEmit && pnpm lint && pnpm test` → `pnpm build` → Playwright smoke (page renders header, ≥1 feed item or the empty state, table rows) → commit `Newsroom: every player and every update, ranked by what matters`.
